Feed88 Reader Guide

Hi, I'm Mohamed

Feed 88 exists because I got tired of algorithms choosing my reading list. No tracking, no "for you" feed, no ads. Just the sites you picked, in the order you picked them.

Two things worth knowing before you start: how the reader works, and how to find RSS links that aren't dead. The second one is the harder problem these days.

Using the reader

1
Add a feed

Open Feeds, tap +, paste an RSS URL. Or browse the catalog — 100 feeds across 11 categories, all alive as of this release.

2
Read

Tap any article. If the feed only ships a snippet, Feed 88 tries to pull the full text automatically.

3
Keep track

Star what matters, filter by Unread or Starred, mark everything read when you're done.

4
Back it up

Export OPML saves your feeds to a file. Import it anywhere else later — no lock-in.

Everything lives on your device. Feeds and settings sit in local storage; articles go to IndexedDB so we don't hit the 5 MB wall.

Finding RSS links that actually work

Most sites hide their feed link now. Many that Google surfaces are years out of date. This is what works today.

Look for the icon

Some sites still show the orange RSS badge in the footer or header. Click it, copy the URL, paste it here.

Try common paths

Append one of these to the site's homepage and see what loads:

/feedWordPress — the most common by far
/rssOlder news sites
/rss.xmlLegacy CNN-style
/feed.xmlAtom — Blogger, many static sites
/atom.xmlGitHub, personal blogs
/index.xmlHugo
/feed/atomBlogger
/.rssMedium, Substack

Example: for example.com, try example.com/feed first, then example.com/rss, and so on.

Read the page source

Right-click → View Page Source, search for rss+xml. You'll usually find:

<link rel="alternate" type="application/rss+xml" href="https://site.com/feed">

The href is the URL you want.

Use a generator

  • RSS.app — rss.app — builds feeds from almost any page
  • Feed43 — feed43.com — old but powerful for tricky sites
  • Politepol — politepol.com — visual feed builder

Privacy, plainly

Feed 88 keeps your feeds, read state, and stars on your device. Nothing about your reading goes to a server we run.

When it fetches a feed, it first tries our Cloudflare Worker (fast, cached 10 min). If that's down, it falls back to public CORS proxies — rss2json, AllOrigins, CodeTabs. Any of those will see the feed URL you're subscribing to.

For full articles, we use r.jina.ai, which sees the article URL. If that matters to you, leave the "fetch full text" feature alone and use the original link instead.

The catalog

100 hand-picked feeds across 11 categories: Football, Health, Tech, Fashion, African News, European News, World News, Fun Facts, Culture, Animals, Environment. Add one with +, or grab a whole category with Add all. The search box filters as you type.

Add all respects whatever's currently visible — so if you search "BBC" first, only the BBC feeds in that section get added.

Notifications optional

Feed 88 doesn't ask for notification permission on load — only when you press this button. If you're on the Android build, it routes through the native bridge instead.
