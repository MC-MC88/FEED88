## 👋 Bienvenue

Feed 88 rassemble les articles des journaux que vous avez choisis, dans une seule liste. Pas de publicité, pas d'algorithme, rien à installer. Le projet existe en deux versions distinctes.

La **version senior** est en français. Gros textes, grands boutons, contraste élevé, trois thèmes. Elle est pensée pour être lue sans effort.

La **version classique** est en anglais. Huit thèmes, interface plus dense, même moteur. Elle vise un usage quotidien sur ordinateur et mobile.

---

## ✨ Ce que vous trouverez

**Deux versions séparées.**  
La version senior privilégie la lisibilité. La version classique privilégie la densité et le choix visuel.

**Catalogue de flux intégré.**  
La version senior propose 50 sources françaises réparties en 9 rubriques. La version classique propose 100 sources internationales réparties en 11 rubriques.

**Import et export OPML.**  
Sauvegardez vos flux dans un fichier, ou importez une liste existante. Aucun verrouillage.

**Lecture complète automatique.**  
Si un flux ne fournit qu'un résumé, Feed 88 tente de récupérer le texte complet de l'article.

**Tout reste sur votre appareil.**  
Les flux et les réglages sont dans le stockage local. Les articles sont dans IndexedDB. Aucun compte, aucun suivi.

---

## 🧭 Comment ça marche

**1. Choisissez une version.**  
Ouvrez le fichier français pour la version senior, le fichier anglais pour la version classique.

**2. Ajoutez des flux.**  
Collez une adresse RSS, ou utilisez le catalogue intégré.

**3. Lisez.**  
Touchez un article. S'il ne contient qu'un résumé, le texte complet est récupéré automatiquement.

**4. Sauvegardez.**  
Exportez vos flux en OPML. Importez-les ailleurs plus tard.

C'est tout. Aucun serveur, aucune inscription.

---

## 🛠️ Petits coups de main

**Quelle version choisir ?**  
La version senior si vous lisez surtout en français et que vous voulez une interface simple. La version classique si vous voulez huit thèmes et un catalogue international.

**Comment trouver l'adresse RSS d'un site ?**  
Essayez `/feed`, `/rss`, `/rss.xml` ou `/feed.xml` après le nom du domaine. La version classique contient un guide plus détaillé.

**Les articles ne s'affichent pas en entier.**  
Certains flux ne fournissent qu'un résumé. Feed 88 essaie de récupérer le texte complet, mais cela peut échouer.

**Est-ce que ça marche hors ligne ?**  
Une fois les articles chargés, oui. L'actualisation a besoin d'une connexion.

## 👋 Welcome

Feed 88 gathers articles from the sites you chose, in a single list. No ads, no algorithm, nothing to install. The project ships as two distinct versions.

The **senior edition** is in French. Large text, big buttons, high contrast, three themes. Built to be read without effort.

The **classic edition** is in English. Eight themes, denser interface, same engine. Built for daily use on desktop and mobile.

---

## ✨ What you'll find

**Two separate versions.**  
The senior edition favours readability. The classic edition favours density and visual choice.

**Built-in feed catalog.**  
The senior edition offers 50 French sources across 9 categories. The classic edition offers 100 international sources across 11 categories.

**OPML import and export.**  
Save your feeds to a file, or import an existing list. No lock-in.

**Automatic full-text fetch.**  
If a feed only provides a summary, Feed 88 tries to fetch the full article text.

**Everything stays on your device.**  
Feeds and settings live in local storage. Articles live in IndexedDB. No account, no tracking.

---

## 🧭 How it works

**1. Pick a version.**  
Open the French file for the senior edition, the English file for the classic edition.

**2. Add feeds.**  
Paste an RSS URL, or use the built-in catalog.

**3. Read.**  
Tap an article. If it only has a summary, the full text is fetched automatically.

**4. Back it up.**  
Export your feeds as OPML. Import them elsewhere later.

That's it. No server, no sign-up.

---

## 🛠️ A little help

**Which version should I use?**  
The senior edition if you mostly read in French and want a simple interface. The classic edition if you want eight themes and an international catalog.

**How do I find a site's RSS URL?**  
Try `/feed`, `/rss`, `/rss.xml` or `/feed.xml` after the domain name. The classic edition has a longer guide.

**Articles do not show in full.**  
Some feeds only ship a summary. Feed 88 tries to fetch the full text, but it may fail.

**Does it work offline?**  
Once articles are loaded, yes. Refreshing needs a connection.
